How the planning agent works

The prototype follows an input → decision → output workflow.

01 · INPUT

Subjects, difficulty, days remaining, daily hours and selected goal.

02 · PLAN

Calculate priority scores, rank subjects and divide available minutes.

03 · OUTPUT

Show an ordered schedule with suggested time for each subject.

Technical scope: This is a rule-based planning-agent prototype, not a trained machine-learning model or connected LLM. For the capstone, your team should test it with sample inputs, compare it with equal-time allocation, record observations, and explain its limitations.
